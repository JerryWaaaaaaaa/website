### Design changes
- **V6 CTA background is now a live halftone.** It runs Figma's "Gradient map → Halftone" effect stack (Figma 260:56525) in WebGL instead of showing a static 1x export.

  - Dot size 5.5, scale 1, softness 1, rotation 0, grid center 50%/50%.

- **Static states.** The halftone is static on touch devices (no `(hover: hover) and (pointer: fine)`) and with `prefers-reduced-motion`. The default output with no cursor matches the Figma export.

### Code changes
- **New `HalftoneImage` component** (`src/sections/v6/halftone/HalftoneImage.tsx`).
  - Props: `src`, `fallbackSrc`, `params: HalftoneParams`, `placement: ImagePlacement`, `interactive?`, `className?`.
  - It renders a wrapper `div.v6-halftone` (aria-hidden) containing the fallback `<img>` and a `<canvas>`. The canvas gets `data-ready` once the first frame draws.
  - The GL pipeline is WebGL2 with three offscreen RGBA8 targets: (1) gradient map, (2) horizontal Gaussian blur, (3) vertical Gaussian blur. The blur radius is `dotSize`, in device texels.
  - Targets are rebuilt whenever the canvas size changes. The canvas is sized via `ResizeObserver` at DPR capped at 2. This produces the blurred texture; the halftone pass reads it and draws to the canvas.
  - The source photo is rasterised through a 2D canvas using the `ImagePlacement` math, then uploaded as a texture.
  - Pointer handling:
    - Listeners go on the nearest `<section>` (`pointermove` / `pointerleave`), because the layer is `pointer-events: none`.
    - Each tick redraws only a scissored box (`POINTER_RADIUS + 3 × dotSize`) unioned with the previous frame's box, so dots the cursor left settle back.
    - A rAF loop runs only while strength is easing.
    - An `IntersectionObserver` pauses it off screen.
  - The canvas uses `preserveDrawingBuffer: true` so scissored partial redraws persist.
  - Context loss calls `preventDefault` and resets `ready`, which brings the fallback back.
  - **Context is not restored.** There is no `webglcontextrestored` handler, so after a loss the fallback image stays.
  - Cleanup disposes all GL resources and listeners.
- **New shader module** (`src/sections/v6/halftone/halftoneShaders.ts`).
  - Exports `QUAD_VERT`, `GRADIENT_MAP_FRAG`, `BLUR_FRAG` (65 taps) and `HALFTONE_FRAG` as GLSL ES 3.0 strings.
  - They are line-for-line ports of Figma's WGSL, so keep the math as is.
  - The only addition is the `u_pointer*` uniforms in the halftone pass. With strength 0 the output is the Figma spec.

### Integration notes for Curry
- **No new dependencies.** It uses raw WebGL2 and browser APIs only (`ResizeObserver`, `IntersectionObserver`, `matchMedia`). Browsers without WebGL2 get the static `bg.webp` with no errors. Both `source.webp` and `bg.webp` must ship in `public/v6/cta/`.
- **Keep the constants.** `CTA_HALFTONE` and `CTA_PLACEMENT` come straight from Figma 260:56525. Don't retune them. If the design changes, re-export the values from Figma rather than editing the shader math.
- **Gotcha: effect dependencies.** The GL `useEffect` depends only on `[src, interactive]`; `params` and `placement` are read through a ref or captured once. They must stay stable module-level constants. If you make them dynamic or CMS-driven, add them to the dependencies and handle re-prepare.
- **Prototype-only / production hardening.**
  - Add a `webglcontextrestored` handler to re-run setup.
  - Consider a second halftone on the same page only with care: each instance owns a context and three full-size targets.
  - Pointer effects are desktop-only by design.
  - The "one or two live shaders per page" rule in DESIGN.md is a budget; don't exceed it.
