### Design changes
- Replaced the old two-row pill filter UI (an "All posts" + product-pill row, plus a separate "Tags" chip row) with two compact dropdown comboboxes — **Product** and **Topic** — followed by a text **Clear** button, laid out in a single wrapping flex row (`.blog-filters`, `gap: 10px`, `margin-bottom: 48px`).
- Filter model narrowed from **multi-select tags → single-select topic**. Only one topic can be active at a time now.
- Trigger chip: 40px tall, `min-inline-size: 180px`, fully-rounded pill (`999px`), `--stroke` border, `--bg-neutral` fill, `--text-primary` text with `--text-secondary` facet label; hover → `--bg-accent-light` bg + `--bg-accent-medium` border; `:active` scale(0.97); focus-visible `--text-highlight` outline. Chevron rotates 180° on open (`transform 160ms var(--ease-out)`).
- Menu opens with an `@starting-style` entry animation (opacity 0→1, `translateY(-4px) scale(0.96)` → rest) over 160ms `--ease-out`. Options are 40px min-height rows, `--rounded-md`, hover `--bg-accent-light`; selected shows a check SVG.
- Selected **Product** option keeps the suite brand tint: `background: color-mix(in srgb, var(--pc) 14%, var(--bg-neutral))`, `color: var(--pc)` — same treatment carried over from the old active product pill.
- Full `prefers-reduced-motion` block added (kills transforms/transitions on trigger, chevron, menu, clear button).
- EmptyState copy: "Nothing is tagged X…" → "Nothing matches X…" (reflects product+topic, not just tags).
- **Token deviations to flag** (see DESIGN.md §Elevation, §Radius): the menu uses a bespoke `box-shadow: 0 12px 32px rgba(15,23,42,0.08)` instead of the `--elevation-*` scale (a floating dropdown should be `--elevation-3`), and `--rounded-xl` (20px) where DESIGN.md maps dropdown panels to `--rounded-lg` (16px).

### Integration notes for Curry
- **No new dependencies.** BlogSelect uses only `react` (`useId`, `useRef`, `useEffect`) and the existing `react-router-dom` (`useNavigate`). No headless-UI / Radix — it's hand-rolled.
- **Keyboard nav is partial (prototype-only).** Open (ArrowDown/Enter/Space), Escape-to-close, and outside-click work, but there's **no roving focus / Up-Down/Home-End/typeahead between options** once the listbox is open, and no `aria-activedescendant`. For production, add full listbox keyboard navigation to meet WCAG combobox pattern.
- **`@starting-style` is relatively new CSS.** Broadly supported by 2026 but degrades gracefully (menu just appears without the enter animation) — confirm against your production browser matrix.
- **Fix the token deviations** noted above (elevation shadow + menu radius) when rebuilding, so the dropdown reads as part of the single coherent elevation stack. Filter state is intentionally URL-driven (shareable links) — keep that source of truth in production.
