### Integration notes for Curry
- **`motion` / Framer Motion is no longer a Nav dependency** — the nav's layout animation is pure CSS now. Check whether `motion/react` is still imported elsewhere before removing it from `package.json`.
- **`V5Tuning` is a prototype-only tuning harness** (live CSS-var dials). Don't ship it — but the values it drives are real: `--kp-badge-shift` (badge alignment) and `--bd5-step-height` need to be baked into production CSS as final constants, not left as runtime dials.
- **Fluid `clamp()` type formulas are hand-fitted, not design tokens** — reconcile the H1/H2/H3 clamps against DESIGN.md's canonical type scale before locking in; they were tuned to interpolate 360→1200px and may not exactly match the spec's discrete sizes.
- **`overflow-x: clip` on html/body** was added to kill horizontal scroll from full-bleed decorations; note it's `clip` (not `hidden`) specifically to preserve `position: sticky`/`fixed` for the nav, `.bd5-media-col`, and `.bu-float` — don't swap it back to `hidden`.
- **Drawer a11y is production-grade** (focus trap, scroll lock, `aria-modal`, focus restore) but was hand-rolled — if production has a shared modal/dialog primitive, prefer porting to that rather than keeping the bespoke trap.
