### Integration notes for Curry
- **`dialkit` is a prototype-only dev dependency.** The nav "Navbar" panel (`useDialKit`), the `?nav` URL sync (`useDialUrlSync` from `./dialUrlSync`), and the accent/neutral/ghost variant switching exist purely for design exploration. In production, drop the dial + URL machinery and ship a single fixed variant — the design default is **`neutral`** (glass fill at rest, brand-tint hover). The three-variant CSS can stay if you want, just hardcode `data-nav-variant="neutral"`.
- **Scroll backdrop is production-ready** but relies on a contract: sections must be `background: transparent` and be wrapped in an element carrying `data-scroll-bg="<color>"`. The recolor triggers when a zone crosses the viewport centerline (`rootMargin: -50% 0px -50% 0px`), and the winning zone also gets `data-active` — OpenPlatformV5's header wash keys off that, so keep the attribute if you keep the wash. `--scroll-bg-color` falls back to `--bg-accent-light` before first scroll.
- **OpenPlatformV5's wash** depends on `@property` (typed custom property) to animate a color — supported in current evergreen browsers; if you must support older engines it degrades to a non-animated (snapping) color, not a break. The dot-grid uses `-webkit-mask-image` + `mask-image`; keep both prefixes.
- Integration-logo assets (`/integration-logos/claude.png`, `openai.png`) are now **unused** by these sections — confirm with Jerry before deleting from the public dir in case other surfaces still reference them.
