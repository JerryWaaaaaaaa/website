### Design changes
- Blog detail header is now a full-bleed gradient hero: the post's mesh cover (`BlogCover`) renders as an absolutely-positioned background behind the meta/title/description block, with a `linear-gradient` fade (`rgba(255,255,255,0)` → `var(--bg-neutral)`, starting at 36%) into the white page as the reader scrolls — mirrors the existing v5 hero-to-white handoff pattern used on the home page.
- Top padding on the hero content increases to `196px` (desktop) / `132px` (≤560px, via `.post-hero-inner`) to sit inside the gradient; the old flush `.post` top padding drops to `8px` since the hero now owns that space.
- Description/lede typography is demoted from a distinct 20px/1.5 lede style to match body copy: `18px`/`1.7` (17px at ≤560px), using `var(--text-secondary)`.
- Meta row (`.blog-meta`) gains `flex-wrap` + `row-gap: 6px` with `white-space: nowrap` on each segment, so author/category/date wrap without breaking a segment mid-text on narrow screens.
- New `.blog-author` style: `var(--text-primary)`, `font-weight: 500` — reads as the bold byline lead ahead of category/date.
- `.bc--hero` (square 1:1, 560px, margin 8/0/40) is removed entirely; replaced by `.bc--hero-bg` (`border-radius: 0`, absolutely positioned, `z-index: 0`) sized as a wide non-square hero background (1120×520) instead of a square inline cover block.

### Code changes
- `BlogCover.tsx`: added optional `width`/`height` props that override the existing square `size` prop, so callers can request non-square renders (used for the 1120×520 hero background). `size` remains the square-only default for card covers.
- `BlogPost.tsx`: restructured render — wraps meta/title/lede in a new `<header className="post-hero">` containing the background `BlogCover` (`bc--hero-bg`), a `<span className="post-hero-fade">` overlay, and a `.post-hero-inner` wrapper for the actual content (back-link, `PostMeta`, `h1`, lede). The old standalone `BlogCover` (`bc--hero`, 560px square, rendered between lede and body) is removed — the cover is no longer duplicated inline in the article body.
- `PostCard.tsx` (`PostMeta`): added `showAuthor` prop (default `false`, opt-in). When true, renders `authorFor(post).name` in a `.blog-author` span followed by a dot separator, before category/date. `BlogPost.tsx` passes `showReadTime showAuthor`; card-grid usage elsewhere is unaffected since the prop defaults off.
