### Design changes
- Hero-to-suite backdrop is now a **crossfade**, not a color tween. The hero's radial gradient (`--gradient-accent`) lives on its own fixed layer (`.scroll-bg-hero`) that fades out (opacity) as the fold scrolls past the hero, revealing the flat `.scroll-bg` beneath. This gives the hero→product-suite handoff the same 600ms trigger-based transition as every other section.
- Transition timing/easing is unchanged from the existing scroll-bg spec: `opacity 600ms cubic-bezier(0.77, 0, 0.175, 1)` (matches the flat layer's `background-color` transition). Under `prefers-reduced-motion: reduce`, both layers drop to `1ms`.
- The v5 hero section (`.hero-v5`) is now `background: transparent` (was `background-image: var(--gradient-accent)`) so the fixed gradient layer shows through.
- Both backdrop layers sit at `z-index: -1`; `.scroll-bg-hero` is painted on top of `.scroll-bg` purely by DOM order (it renders second).
- Refreshed the 5 `meeting-deliverable/gallery-cards-*.png` assets (near-identical re-exports, byte-level only).

### Integration notes for Curry
- **No new dependencies.** Everything is plain React refs + IntersectionObserver + CSS; nothing to `npm install`.
- **Contract to preserve:** the effect keys entirely off DOM attributes — `[data-scroll-bg="<color>"]` marks a recolor zone and `[data-hero]` marks the single gradient zone. If you re-template the sections in production, keep emitting those attributes or the backdrop won't drive.
- **The radial gradient must stay on the fixed layer, not the hero section.** Radial can't tween to a flat color, which is the whole reason for the opacity crossfade — don't "simplify" it back onto `.hero-v5`.
- **v5-only:** this two-layer behavior is gated to the v5 page version (the only one that emits `BgZone`s). The no-zone guard exists so the shared component stays safe on v1–v4; keep that guard if the component is reused. Tokens `--gradient-accent` and `--bg-accent-light` are the source of truth in `src/index.css` / DESIGN.md — reference them, don't hardcode.
