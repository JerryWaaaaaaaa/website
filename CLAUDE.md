# Project rules

Zoom AI Create microsite — Vite + React 19 + TypeScript.

## Pull Requests

- **Always attach a screenshot of any UI change to the PR.** If a change affects
  what the user sees — layout, styling, components, copy, motion, responsive
  behavior — include a screenshot of the result in the PR description.
- Prefer **before / after** screenshots when modifying existing UI.
- Non-UI changes (build config, docs, refactors with no visual effect) are
  exempt from this requirement.
- Capture screenshots from the running dev server (`npm run dev`) or with the
  Playwright-based `webapp-testing` tooling available in this repo.
